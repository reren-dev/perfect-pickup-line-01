An entry for [The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6) on [make.fun](https://make.fun): one short pickup line an AI agent could actually say out loud.

The program (`main.py`, pure Python 3 standard library) writes the line to `/output/entry.txt`:

> I ran a million simulations of this moment. In every one, you smiled, so I stopped simulating and came to say hi.

Deterministic: two runs write byte-identical output.

## Run it

```sh
python3 main.py
```
